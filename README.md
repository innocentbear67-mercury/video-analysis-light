# Video Analysis Light — Hermes Skill

A [Hermes Agent](https://hermes-agent.nousresearch.com/docs) skill: transcript-first YouTube analysis using **whatever model is currently serving the chat** — no hard-coded providers, no extra API keys.

Switch your chat to any model Hermes supports (`openai-codex/gpt-5.6-sol`, `openrouter/z-ai/glm-5.3`, anything else) and the analysis follows. The script resolves the live session runtime from Hermes's `state.db`, including session-scoped `/model` switches.

## What it does

```
transcript fetch → chunk (~40K chars, 2K overlap) → dense per-chunk notes via the active model
                 → one synthesis call merges the notes → four-section analysis
```

Default output, in order:

1. **Summary** — the whole video as one compact list. One-line core idea + 4–8 bullets.
2. **Analysis (light)** — jargon in plain language, the core idea, how the pieces fit.
3. **Caveats** — unverified claims, hidden assumptions, what could invalidate the argument.
4. **Relate to me** — LEARN (2–4 takeaways) / AVOID (traps), given the viewer's `--context` blurb.

Style is deliberately concise: short tight sentences, plain words, nothing that doesn't earn its place.

## Design notes

- **Runtime-agnostic by construction.** Every model call goes through `hermes chat` with the resolved `--provider`/`--model`, reusing Hermes's credential pools and transports (API-key and OAuth/subscription providers both work). Zero model names in the code.
- **Transcript is the whole input.** Visual-only charts, slides, and on-screen text are invisible — the skill says so instead of pretending.
- **No silent fallbacks.** A video without captions fails with a clear error. Nothing runs that you didn't ask for.
- **Chunked + synthesized** for long videos, always by the same runtime the chat is using.

## Install

Copy into your Hermes skills directory:

```bash
git clone https://github.com/innocentbear67-mercury/video-analysis-light.git
mkdir -p ~/.hermes/skills/video-analysis-light
cp video-analysis-light/{SKILL.md,scripts} ~/.hermes/skills/video-analysis-light/ -r
```

Requires: a Hermes Agent install and `youtube-transcript-api` in the Hermes venv (`uv pip install youtube-transcript-api`).

## Usage

```bash
# Four-section analysis with viewer context
hermes-agent/venv/bin/python3 scripts/analyze_video.py "URL" \
  --context "Who the viewer is and what they care about."

# Custom question
hermes-agent/venv/bin/python3 scripts/analyze_video.py "URL" \
  --prompt "What does this video get wrong?"

# Override runtime (e.g. running outside a chat session)
hermes-agent/venv/bin/python3 scripts/analyze_video.py "URL" \
  --provider openrouter --model z-ai/glm-5.3
```

## Limitations

- Videos without captions are unsupported — the script exits with an error.
- Best for videos under ~30 minutes; longer videos get a warning and a thinner summary.
- Autogenerated captions can corrupt names and figures — verify important numbers elsewhere.
